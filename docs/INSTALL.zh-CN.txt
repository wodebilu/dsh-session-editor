会话工具箱（Session Toolkit for DSH）安装说明
================================================

给 DSH 网页端加上：
- 侧边栏会话菜单里的「删除会话…」
- 已完成回答操作行里的「重新生成 / 编辑提问 / 删除此轮及之后」
- 用户消息气泡上的「复制 / 编辑我的输入」

无第三方依赖、无网络请求。


方式一：从 GitHub 安装（推荐）
------------------------------
1. 打开 DSH → 左侧「插件」→「添加插件」。
2. 粘贴仓库地址，例如：
   https://github.com/your-name/dsh-session-toolkit
   （或 github:your-name/dsh-session-toolkit）
3. 安装，然后重启一次 DSH。

方式二：从 ZIP / 本地文件夹安装
--------------------------------
1. 下载仓库 ZIP，解压到一个以后不会移动的位置。
2. 双击 tools\copy-install-path.cmd，它会把仓库根目录（含 package.json）
   的绝对路径复制到剪贴板。
   也可以按住 Shift 右键点击该文件夹 →「复制文件地址」。
3. 在「添加插件」里粘贴这个路径 → 安装 → 重启 DSH。

注意：文件夹安装是 link: 依赖，装完不能移动或删除该文件夹。


先移除旧版本
------------
早期版本包名是 @local/dsh-session-toolkit。如果装过，先在
「插件 → Installed plugins」里移除它，否则两个客户端模块会注册同一批 slot。


验证
----
重启后：
- 任意会话行「…」菜单里出现「删除会话…」。
- 已完成回答的操作行出现三个小图标：重新生成、编辑提问、删除此轮。
- 悬停在用户消息气泡上出现「复制 / 编辑我的输入」。

没有的话：刷新页面；再检查「插件」页里这个 bundle 是否为 On。


使用与语义
----------
- 删除会话：直接删磁盘，不可恢复。
- 编辑/删除某一轮、重新生成：会生成一个新会话接管当前对话，然后删除原会话。
  你看到的对话立刻变成修改后的样子，但会话 id 会变、没有分支历史可回退。
- 编辑我的输入：同样走替换并删除原会话的流程。
- 只能「从这一轮起」截断，不能只删中间一条并保留后面的对话。


风险
----
- 破坏性工具，没有撤销。介意数据请先备份 DSH 的 sessions 目录。
- 依赖 DSH 未公开的内部 API，升级 DSH 可能失效。
- 插件替换了用户消息渲染器，DSH 改动该节点契约时可能影响用户消息显示。
