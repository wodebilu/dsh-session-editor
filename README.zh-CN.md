# 会话工具箱（Session Toolkit for DSH）

**非官方** DeepSeek Harness（DSH）插件，与 DeepSeek 官方无关。

给 DSH 网页端加上会话删除，以及类似 SillyTavern 的“直接改、直接删”对话编辑。

> **设计上就是破坏性的。** 删除会话会把 JSONL 日志从磁盘移除；编辑/删除某一轮会用新会话替换并删除原会话。没有撤销。介意数据的话，先备份 DSH 的 `sessions` 目录。

[English](README.md)

## 功能

| 操作 | 位置 | 行为 |
|---|---|---|
| 删除会话 | 会话行 `…` 菜单 →「删除会话…」 | 确认后停止进行中的工作、归档，并从磁盘删除会话目录。 |
| 重新生成 | 已完成回答的操作行 | 确认 → 用同一提问生成新会话 → 打开 → 删除原会话。 |
| 编辑提问并重发 | 同一操作行 | 确认 + 编辑框 → 用新提问生成新会话 → 删除原会话。 |
| 删除此轮及之后 | 同一操作行 | 生成截止到该轮之前的新会话 → 删除原会话。 |
| 编辑我的输入 | 悬停在用户消息气泡上 | 复制 / 编辑自己的消息；同样走替换并删除原会话的流程。 |

## “直接改 / 直接删”是怎么实现的

DSH 的会话日志是 append-only 的，不支持原地改写。所以每次编辑会：

1. 在目标轮之前 fork 一个子会话（标题保持不变）；
2. 需要重发时把提问发进子会话；
3. 打开子会话；
4. 删除源会话。

你看到的对话立刻变成修改后的内容，原会话和分支历史都不再保留。

代价：

- 会话 id 会变，侧边栏那一行被替换（标题保留）；
- 没有可回退的分支历史；
- 只能“从这一轮起”截断，不能“只删中间一条、保留后面”；
- 改文字会重新生成回答，不是纯文本替换。

## 环境要求

- 在 DSH `0.2.1-rc.2` 上测试。插件使用了未公开的内部 API（slot key、`sessionPersistence.locate`、`agent.session.seq`、`persistence.flush`），DSH 升级可能导致失效。建议固定版本并关注更新日志。
- 无第三方依赖、无网络请求、无遥测。

## 安装

### 从 GitHub 安装

1. DSH 左侧 **插件** → **添加插件**。
2. 粘贴仓库地址：

   ```text
   https://github.com/your-name/dsh-session-toolkit
   ```

   或 `github:your-name/dsh-session-toolkit`。
3. 安装后重启一次 DSH。

### 从本地文件夹 / ZIP 安装

1. 下载仓库 ZIP，解压到一个以后不会移动的位置。
2. 在 **添加插件** 里粘贴解压后文件夹的绝对路径（包含 `package.json` 的那一层）。
3. 安装并重启 DSH。

> 文件夹安装是 `link:` 依赖，装完不能移动或删除该文件夹；Git/tarball 安装会把包复制进 profile，移动安全。

### 先移除旧的本地版本

早期版本使用的包名是 `@local/dsh-session-toolkit`。安装本版本前，先在 **插件 → Installed plugins** 里移除旧的 bundle，否则两个客户端模块会注册同一批 slot。

## 使用

- 删除会话：会话行 `…` →「删除会话…」→ 确认。
- 编辑/删除某一轮：悬停在已完成回答下的操作行 → 铅笔 / 垃圾桶 / 循环箭头 → 确认。
- 编辑自己的消息：悬停在用户气泡上 → 复制 / 铅笔。

删除命令会作为普通命令行记录。会话删除自己时，Host 会等 `command/done` 落盘后再移除会话目录，通常在几十毫秒内完成。

## 兼容性与风险

- **替换了用户消息渲染器**：插件注册 `conversation.chat.node` 的 `user` 键来加悬停操作，并复用官方 `conversation.chat.user.content` 工厂。DSH 一旦改动该节点契约，用户消息渲染可能受影响，直到插件跟进。
- **依赖内部 API**：见“环境要求”。这是社区插件，不是稳定的公开扩展点。
- **无担保**：这是破坏性工具，请只用在可以丢失的数据上，并保留备份。

## 开发

无需构建，纯 ESM Host 代码 + 浏览器 bundle。

```bash
npm test
# 等价于：
node test/host-smoke.mjs
node test/client-smoke.mjs
```

Host 测试使用临时目录，不会触碰真实会话。
